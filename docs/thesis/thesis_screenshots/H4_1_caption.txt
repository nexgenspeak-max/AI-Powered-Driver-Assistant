Hình 4.1. Sơ đồ kiến trúc tổng thể theo lớp (Presentation → Authentication → Client API → Realtime media → API microservices → Data → Monitoring). Mỗi hộp là một thành phần thật trong kho mã; mũi tên đánh số ①–⑱ là luồng nóng tài xế (đăng nhập JWT → token thoại → LiveKit → llm-orchestrator → external-api-service → DynamoDB) và luồng hỗ trợ (kênh điện thoại, bản ghi cuộc gọi, ops). llm-orchestrator chỉ gọi HTTP tới external-api-service (không mở DB). Xác thực bằng identity-service (JWT), không dùng Cognito.
