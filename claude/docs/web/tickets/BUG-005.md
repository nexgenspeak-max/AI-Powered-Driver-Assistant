# BUG-005 — customer-web/driver-web chưa responsive cho iPad và điện thoại

| | |
|---|---|
| **Loại** | Bug |
| **Service** | customer-web, driver-web |
| **Mức độ** | 🟡 Trung bình |
| **Trạng thái** | 🆕 Mới phát hiện, chưa sửa |
| **Liên quan** | [04_BUG_TRACKER.md](../04_BUG_TRACKER.md) |

## Mô tả

UI của cả `customer-web` và `driver-web` hiện chưa có breakpoint responsive cho tablet (iPad) và điện thoại — giao diện đang dựng cứng theo layout desktop. Phát hiện qua test thực tế trên thiết bị, chưa xác định điểm gãy layout cụ thể (tràn màn hình, chồng chéo phần tử, v.v. — cần khảo sát thêm khi bắt tay sửa).

## Yêu cầu / Acceptance Criteria

- [ ] Xác định danh sách màn hình/trang chính cần responsive (ví dụ: đặt chuyến, theo dõi chuyến, AI assistant, login...).
- [ ] Thêm breakpoint cho tablet (iPad, ~768–1024px) và mobile (~<768px) cho từng trang đó.
- [ ] Test thủ công trên ít nhất: 1 kích thước điện thoại, 1 kích thước iPad (hoặc DevTools responsive mode tương đương).
- [ ] Không phá vỡ layout desktop hiện có.

## Việc cần làm

1. Liệt kê cụ thể các màn hình bị lỗi và kiểu lỗi (chụp màn hình nếu có) — hiện chưa có, cần bổ sung khi khảo sát.
2. Kiểm tra CSS/framework đang dùng (có sẵn hệ thống breakpoint chưa, hay cần thêm mới).
3. Sửa từng trang, ưu tiên các luồng chính (đặt chuyến, gọi AI/tài xế) trước các trang phụ.
4. Test trên thiết bị thật hoặc responsive mode, xác nhận với người báo bug trước khi đóng ticket.
5. Cập nhật [04_BUG_TRACKER.md](../04_BUG_TRACKER.md) → ✅, ghi log vào [02_WORK_LOG.md](../02_WORK_LOG.md).

## Ghi chú

Ticket này tạo dựa trên báo cáo thực tế của người dùng, chưa qua khảo sát code — cần bổ sung chi tiết lỗi cụ thể (tên trang, kích thước màn hình, mô tả/ảnh chụp) trước khi bắt đầu sửa.
