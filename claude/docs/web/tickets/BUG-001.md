# BUG-001 — Trạng thái trip lưu lẫn lộn uppercase/lowercase

| | |
|---|---|
| **Loại** | Bug |
| **Service** | trip-service, admin-panel |
| **Mức độ** | 🟡 Trung bình |
| **Trạng thái** | 🔨 Đang sửa (uncommitted tại thời điểm tạo ticket) |
| **Liên quan** | [04_BUG_TRACKER.md](../04_BUG_TRACKER.md) |

## Mô tả

Trạng thái chuyến đi (trip status) được ghi bằng 2 kiểu khác nhau ở các nơi khác nhau: uppercase (`ARRIVED_PICKUP`, `PICKED_UP`, `CANCELLED_BY_DRIVER`) từ voice-agent, và lowercase ở các bảng tra cứu UI của admin-panel. Kết quả: UI không khớp được giá trị → hiển thị sai hoặc thiếu trạng thái.

## Nguyên nhân

voice-agent (Python) ghi trạng thái dạng uppercase khi cập nhật trip, trong khi admin-panel và các phần khác của trip-service dùng lowercase làm chuẩn.

## Cách sửa (đang thực hiện)

- Chuẩn hóa toàn bộ về lowercase (`arrived_pickup`, `picked_up`), bỏ `CANCELLED_BY_DRIVER` dùng chung `cancelled`.
- Thêm hàm `normalizeTripStatus()` trong `src/frontend/admin-panel/src/constants/status.ts` để tự chuyển đổi các giá trị cũ về chuẩn mới (phòng dữ liệu cũ trong DB còn uppercase).
- File bị ảnh hưởng: `trip-service/routes/trips.ts`, `trip-service/routes/drivers.ts`, `trip-service/services/driverContextService.ts`, `admin-panel/constants/status.ts`.

## Việc còn lại

- [ ] Kiểm tra dữ liệu cũ trong DynamoDB — có cần migrate dữ liệu đã lưu hay chỉ chuẩn hóa lúc đọc (`normalizeTripStatus`) là đủ.
